Command-line interface library for .NET console tools. Provides a simple API for parsing command-line arguments, options and switches, and executing commands. Optional library for AppHost support for dependency injection and hosting capabilities.

- https://www.nuget.org/packages/Kokoabim.CommandLineInterface
